# 泄露密钥影响面调查台 · 使用说明

一个基于 **Phoenix 1.8 + LiveView** 的本地应急取证工具：导入云操作审计日志
（CloudTrail 风格 JSONL），按泄露的访问密钥还原全部调用，自动梳理影响面并把
每一步串成攻击者的完整操作经过。**无外部数据库依赖，数据只在进程内存中，
重启即清空。**

## 运行

```bash
mix setup      # 首次：拉依赖、构建前端资源
mix phx.server # 启动，访问 http://localhost:4000
```

测试与质量检查：

```bash
mix test       # 38 个测试（解析、分类、报告、LiveView 交互）
mix precommit  # 零警告编译 + 依赖检查 + 格式化 + 测试
```

## 三种导入方式

1. **载入内置模拟日志**（首页按钮）：已内置一条含完整攻击链的 58 条事件样例。
2. **文件上传**：`.jsonl` / `.ndjson` / `.txt`，每行一条事件，上限 20MB，支持拖拽。
3. **直接粘贴**：把 JSONL 文本贴进文本框解析。

导入后系统列出数据集中的全部访问密钥并按调用次数排序，自动预选最可疑的一把；
也可点选任意密钥重新生成报告（用来对比正常身份的基线流量）。

## 架构

```
lib/credential_breach/
  audit/
    event.ex       原始 JSON → 归一化事件结构
    classifier.ex  单事件分类：杀伤链阶段 / 类别 / 严重级 / 中文动作描述
    importer.ex    JSONL 解析、坏行容错、去重、时间排序
    report.ex      按密钥过滤、吊销检测、各影响面聚合、阶段叙事
    meta.ex        阶段/类别/严重级/IP 威胁标签的展示元数据
    store.ex       进程内 GenServer 存储（无数据库）
    dataset.ex     一次导入的数据集
  investigations.ex  Web 层调用的上下文门面
lib/credential_breach_web/
  live/            主 LiveView + 导入面板组件 + 六个标签页渲染模块
  components/      调查台专用 UI 组件（徽章、统计卡、时间线等）
```

## 两个值得注意的解析陷阱（已在代码与测试中固化）

- **PCRE `\R` 与中文**：`String.split(~r/\R/)` 的 `\R` 在 UTF-8 模式下还匹配 U+0085，
  而中文字符尾字节可能恰为 `0x85`，会把含中文的日志行从中间劈开。改用按 `"\n"` 切分。
- **管道与 `||` 的优先级**：`x || [] |> f()` 被解析成 `x || ([] |> f())`，
  `x` 非空时整段管道被跳过。必须加括号 `(x || []) |> f()`。
